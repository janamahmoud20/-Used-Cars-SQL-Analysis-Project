# Used Cars SQL Analysis Project

## Project Overview

This project analyses a used cars dataset using SQL Server. The analysis explores car brands, models, prices, fuel types, transmissions, vehicle conditions, and manufacturing years to identify useful trends and insights.

## Dataset

- Total records: 2,250
- Number of columns: 10
- Main features:
  - Car ID
  - Brand
  - Model
  - Year
  - Engine Size
  - Fuel Type
  - Transmission
  - Mileage
  - Condition
  - Price

## Tools Used

- SQL Server
- Azure Data Studio
- Python
- Pandas
- Jupyter Notebook
- Docker

## SQL Analysis

The project includes the following analyses:

1. Total number of cars by brand
2. Average car price by brand
3. Most common car models
4. Fuel type analysis
5. Transmission analysis
6. Car condition analysis
7. Top 10 most expensive cars
8. Average car price by manufacturing year

## Key Insights

- Car inventory varies across different brands.
- Average prices differ between brands and vehicle categories.
- Fuel type and transmission provide useful information about the vehicle distribution.
- Car condition can affect average vehicle prices.
- Manufacturing year is useful for analysing price trends.
