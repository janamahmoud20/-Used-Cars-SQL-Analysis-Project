# Used Cars SQL Analysis Project

## Project Overview
This project analyses a used cars dataset using Microsoft SQL Server and Azure Data Studio.

## Database
- Database Name: UsedCarsDB
- Table Name: Cars
- Number of Records: 10

## Columns
- CarID
- Brand
- Model
- Year
- EngineSize
- FuelType
- Transmission
- Mileage
- CarCondition
- Price

## SQL Analysis
The project includes:

1. Displaying all car records
2. Calculating the number of cars for each brand
3. Calculating the average price for each brand
4. Finding the top 5 most expensive cars

## Tools Used
- Microsoft SQL Server
- Azure Data Studio
- SQL

## Key Findings
- Tesla has the highest average price.
- Tesla Model X is the most expensive car in the dataset.
- The analysis compares car prices across different brands.
